# Ejercicios de PHP

Ejercicios del tema de PHP (elementos básicos del lenguaje). Todos los ejercicios de la unidad se guardan dentro de `ud1/`, y dentro de esa carpeta, `ejercicios1/` contiene estos primeros ejercicios cortos (sintaxis básica, variables, constantes, operadores y estructuras de control).

## ud1/ejercicios1/

- **info_basica.php** — Nombre y año de nacimiento con variables.
- **area_circulo.php** — Área de un círculo usando una constante `PI`.
- **curriculum.php** — Variables variables para mostrar currículum en varios idiomas.
- **prueba_if.php** — Comparación de notas con `if..else` / `if..elseif..else`.
- **contador.php** — Contadores con `for` y `while`, intercalando HTML.
